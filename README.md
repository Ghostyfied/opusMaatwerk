# Opus Maatwerk — Website

New website for [Opus Maatwerk](https://opusmaatwerk.nl/) — custom carpentry & wooden garden buildings (houten buitenverblijven) by Tijmen Wehlburg, Culemborg NL.

Static site built with Vue 3 + Vite (pre-rendered with vite-ssg), styled with Tailwind CSS, deployed to GitHub Pages.

**Status:** planning. See [PLAN.md](./PLAN.md) for the full redesign plan: current-site analysis, positioning, sitemap, design system, tech architecture, and implementation phases.
