# Project Buitenwerk — Website

Website for a **new company** (name, logo, and domain TBD — "Project Buitenwerk" is a working title) by carpenter Tijmen Wehlburg, Culemborg NL: custom wooden garden buildings (houten buitenverblijven).

Static site built with Vue 3 + Vite (pre-rendered with vite-ssg), styled with Tailwind CSS, deployed to GitHub Pages. Built brand-agnostic: all identity (name, mark, colors, domain) lives in a small placeholder config/token layer that the final branding replaces in one pass.

**Status:** planning. See [PLAN.md](./PLAN.md) for the full plan: source-material analysis, positioning, sitemap, provisional design system, placeholder/brand-swap strategy, tech architecture, and implementation phases.
